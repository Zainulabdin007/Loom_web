Meet Frame

The AI IDE that learns you.

Frame is a local-first AI coding IDE that personalizes itself to how you write code. It is a familiar editor with a chat assistant on the side, running entirely on your machine, with nothing ever leaving your device.

[ demo clip: product overview ]

Why Frame

Not another cloud assistant.

Cursor and Copilot ship your code to their servers and hand everyone the same generic model. Frame runs privately on your machine and becomes your model, shaped by the way you actually build, one project at a time.

Cursor & Copilot

  • Your code is sent to the cloud
  • One generic model for everyone
  • No memory of how you work

Frame

  • Nothing leaves your device
  • A model tuned to you, per project
  • Learns your patterns over time

How it works

Four steps. One loop.

01

You code

Work exactly like you do today. Frame lives in your editor with a chat assistant one panel over.

02

Frame listens

It quietly notes what you accept, edit, and revert. That is the real signal of how you write code.

03

You confirm

Every change to your model is shown as a before / after. You choose what sticks. Nothing is silent.

04

Frame improves

Offline, between sessions, it refines itself to match your style. Never mid-flow. Only after it is sure.

Features

Built to become yours.

Per-project personalization

Each project gets its own adapter, so conventions from one codebase never bleed into another.

Fully local inference

A 7B model runs entirely on your machine. No cloud round-trips, no waiting on someone else's GPUs.

Zero data policy

Code, patterns, and preferences never touch a server. Not for inference, not for training, not ever.

Validated learning

Changes only apply after your signals stay consistent across multiple sessions, so it never overfits to a bad day.

Grows with you

The longer you use Frame, the closer its output gets to code you'd have written yourself.

Privacy

Privacy isn't a setting. It's the architecture.

Frame is built so that private-by-default is not a promise you have to trust. It is the only way the software can run. There is no server to send data to.

  • Zero data leaves your machine
  • No telemetry
  • No cloud inference
  • No training on your data anywhere but locally
