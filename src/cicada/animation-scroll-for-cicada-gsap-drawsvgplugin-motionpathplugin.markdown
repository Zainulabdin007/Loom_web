Animation Scroll for Cicada | GSAP, DrawSVGPlugin, MotionPathPlugin
-------------------------------------------------------------------
Here to present the biotech website concept in the field of genomics. The website provides information about the company's products and services.

The main highlight of the website is the implementation of SVG rendering using the GSAP library, which allows for smooth and interactive animations of components, such as butterflies. The use of scroll-based controls enhances the user experience by enabling seamless navigation and interaction with the website's content.
